# Scraper benchmark fixtures

Made-up test files for comparing web scraping tools. Every business name, price and
address here is fictional. Nothing in this repository is real customer data.

- `F03/` a sitemap index pointing to 30 smaller sitemaps (90 made-up addresses)
- `K01/` a PDF price table with empty cells
- `K04/` a right-to-left (Arabic) PDF with bracketed phrases
- `L03/` a spreadsheet with three sheets (one hidden), merged cells and formulas
- `W05/` a page whose price changes during the test
